# Crypto Growth Screener

سیستم شناسایی کوین‌های میان‌رده (رتبه مارکت‌کپ ۵۰ تا ۵۰۰) با پتانسیل رشد کوتاه/میان‌مدت،
بر اساس ترکیب چهار معیار: مومنتوم قیمتی، شکست مقاومت (Breakout)، RSI و MACD.

⚠️ **این ابزار توصیه سرمایه‌گذاری نیست.** خروجی صرفاً یک لیست کاندید برای بررسی بیشتر است.
بازار کریپتو پرنوسان است و هیچ الگویی تضمین سود نمی‌دهد.

---

## نحوه کارکرد

1. لیست کوین‌های رتبه ۵۰-۵۰۰ از **CoinGecko** گرفته می‌شود.
2. برای هر کوین، کندل‌های قیمتی از **Binance** (تایم‌فریم ۴ ساعته) دریافت می‌شود.
3. چهار اندیکاتور محاسبه و امتیازدهی می‌شود (جمعاً از ۱۰۰):
   - مومنتوم قیمتی (۳۰ امتیاز)
   - شکست مقاومت (۳۰ امتیاز)
   - RSI (۲۰ امتیاز)
   - MACD (۲۰ امتیاز)
4. کوین‌هایی با امتیاز بالای آستانه تعیین‌شده، رتبه‌بندی و به تلگرام ارسال می‌شوند.
5. با GitHub Actions هر ۴ ساعت به‌طور خودکار اجرا می‌شود.

---

## راه‌اندازی (مرحله به مرحله)

### ۱. ساخت بات تلگرام
1. در تلگرام به [@BotFather](https://t.me/BotFather) پیام بده.
2. دستور `/newbot` را بزن و مراحل را دنبال کن.
3. **Token** ای که می‌دهد را نگه دار (چیزی شبیه `123456:ABC-DEF...`).

### ۲. گرفتن Chat ID
1. به بات ساخته‌شده یک پیام بده (مثلاً "سلام").
2. آدرس زیر را در مرورگر باز کن (`<TOKEN>` را با توکن واقعی جایگزین کن):
   ```
   https://api.telegram.org/bot<TOKEN>/getUpdates
   ```
3. در خروجی دنبال `"chat":{"id":...}` بگرد؛ همان عدد Chat ID توست.

### ۳. ساخت ریپازیتوری در گیت‌هاب
1. یک ریپوی جدید بساز (مثلاً `crypto-growth-screener`).
2. فایل‌های این پروژه (`screener.py`, `requirements.txt`, `.github/workflows/run.yml`, `README.md`) را در آن آپلود کن — می‌توانی مستقیم از رابط وب گیت‌هاب (Add file → Upload files) استفاده کنی، نیازی به خط فرمان نیست.

### ۴. تنظیم Secrets (اطلاعات محرمانه)
در ریپو برو به:
`Settings → Secrets and variables → Actions → New repository secret`

دو مقدار زیر را اضافه کن:
| Name | Value |
|---|---|
| `TELEGRAM_BOT_TOKEN` | توکن باتی که از BotFather گرفتی |
| `TELEGRAM_CHAT_ID` | Chat ID که در مرحله ۲ پیدا کردی |

### ۵. اجرای اولیه (تست دستی)
1. برو به تب **Actions** در ریپو.
2. روی workflow با نام **Crypto Growth Screener** کلیک کن.
3. دکمه **Run workflow** را بزن.
4. بعد از چند دقیقه، پیام نتیجه باید در تلگرام برایت بیاید.

از این پس، هر ۴ ساعت به‌طور خودکار اجرا می‌شود (بدون نیاز به کار دستی).

## تنظیمات قابل تغییر

در ابتدای فایل `screener.py` می‌توانی این مقادیر را عوض کنی:

| متغیر | توضیح | مقدار پیش‌فرض |
|---|---|---|
| `MIN_MARKET_CAP_RANK` / `MAX_MARKET_CAP_RANK` | بازه رتبه مارکت‌کپ | ۵۰ تا ۵۰۰ |
| `KLINE_INTERVAL` | تایم‌فریم کندل | `4h` |
| `MIN_SCORE_TO_REPORT` | حداقل امتیاز برای نمایش در گزارش | ۵۰ |
| `TOP_N_RESULTS` | تعداد کوین برتر در گزارش | ۱۰ |

برای تغییر زمان‌بندی اجرا (مثلاً هر ۲ ساعت به‌جای ۴ ساعت)، خط `cron` را در
`.github/workflows/run.yml` تغییر بده.

## محدودیت‌ها (مهم)

- کوین‌هایی که روی Binance جفت‌ارز USDT ندارند، به‌طور خودکار رد می‌شوند.
- این سیستم بر پایه تحلیل تکنیکال است؛ اخبار، تغییرات فاندامنتال یا ریسک‌های ناگهانی (هک، رگ‌پول و...) را در نظر نمی‌گیرد.
- امتیاز بالا به معنی "قطعاً رشد می‌کند" نیست — فقط یعنی چند سیگنال تکنیکال هم‌زمان مثبت بوده‌اند.
- هیچ خرید یا فروش خودکاری انجام نمی‌شود؛ این نسخه فقط اطلاع‌رسانی می‌کند.
